# 正文接入、蒙版判断与美元用量：第一版

> 2026-10-03 更新：当前实现已改为**先完成封面 OCR**，再按标题与 OCR 文字合计的非空白 Unicode 码点数决定是否补取正文。合计 **≤ 20** 才尝试页面缓存/详情请求；**> 20** 则不发正文请求，历史记录为 `skipped`，Jev 只接收标题与封面文字。空格和 OCR 换行不计数，标点计数。按规则跳过不视为正文请求失败；OCR 错误、截断或明确指向未读取图片/视频的文字仍禁止自动过滤。实际正文请求起始间隔现为至少 **10 秒**，单帖 OCR 与正文不再并行。下文保留了 2026-09-26 第一版的原始实现与验证记录，不能将其中的 2 秒间隔、并行流程或 78 项测试当作当前状态。

2026-09-26。本轮已实现、构建，源码与验证记录一同纳入本次版本提交。完整真实分类链路仍待 Jev 连接恢复后验收。

## 已实现

- 首页不跳转：通过已有 scripting 权限，在 MAIN world 使用页面客户端补取当前卡片详情。优先匹配详情缓存；动态识别已加载的接口模块，不写死模块编号，不执行全部模块。
- 正文起始请求间隔 2 秒、单页面并发 1、8 秒超时、同帖缓存/去重。拒绝或超时后停止本页后续正文请求，刷新后才能重试；不绕过验证或限流。不同首页标签页各有队列，不承诺全账户全局限速。
- 只 OCR 封面，与正文并行。标题、正文、封面文字分别进入 Jev structured state，一篇一次请求，六题 Noul；不下载后续图片、不转写视频。
- 正文状态/获取途径/耗时、文字及截断标记进入历史；审计保存真正发送的 state、题目、原始输出和单次美元估算。
- 蒙版先显示简明原因，再分推广/情绪两组显示真正触发的概率与阈值，不把关闭的过滤类别当作遮挡原因。短卡片可滚动，查看原文可恢复内容。
- 面板累计调用次数、已返回 input tokens、估算美元；按本插件安装中的所有密钥/标签页合计，非账户余额。清空检测历史或刷新页面不清零费用。

## 费用口径

当前固定 `jev-1.13.0`。2026-09-26 官方价格为每百万输入 tokens **$0.042**，输出免费。

`估算 USD = API usage.input_tokens × 0.042 / 1,000,000`

只接受匹配模型及合法整数用量；不按字符数或帖子数猜 token。缺失用量、坏用量、其他模型均标未知。
调用发送前先持久化次数，响应拿到用量再累计价格；多请求写入串行化，避免并发丢账。
网络失败、响应丢失、worker 被回收时，已记录的请求仍在“未知/处理中”计数里，不认为免费。
只有未知请求时直接显示“费用未知”；部分未知时金额是已知部分估算。优惠、最低计费、账户其他调用均不在此数字中。
不查询账户余额，不做充值、额度扣减或账单系统。实际扣款与剩余额度以 TypeSafe 后台为准。

参考：[官方模型价格](https://docs.typesafe.ai/models)、[API 用量字段](https://docs.typesafe.ai/api)。

## 保守边界

- 输入超出标题 500 / 正文 8000 / 封面文字 4000 Unicode 码点时截断并标记，禁止自动过滤。
- 正文失败或为空、OCR 失败、正文不足 24 码点，或不足 120 码点且明显指向“看图/视频”：首版不按低信息自动过滤。
- 上述长度是保守工程启发式，不是语义完整性证明；后续需要中文标注样本验证。
- 获取非空正文仍不等于读完所有图片/视频。模型仅判断已取得文字，材料不足时保留卡片。
- 六题仍采用原来的保守阈值作为试用起点，但商业过滤不再单凭销售号召触发；新提示词尚未做准确率标定。
- 页面世界不接触 Jev 密钥，不导出 Cookie/签名/访问令牌；正文读取有站内请求，不能保证无服务端访问记录。

## 验证结果

- 自动化：78 项（正文解析/缓存/ID 校验/超时/拒绝、间隔/去重/取消、结构化输入/截断/证据守卫、真实扫描装配的单次调用与暂停后不调用、并发美元记账、历史/面板回归等）。
- 类型检查、构建、diff 空白检查通过。
- 真实 Chrome 扩展通道：两篇正文请求，首篇 `empty`、20 张图；第二篇 `success`、374 字符、5 张图。路径均保持 `/explore`，不记录原文、令牌或作者信息。
- 实际扩展面板显示 OCR 绿色健康（本轮没有重新验证所有封面识别准确率）。
- 离线渲染使用真实面板/蒙版代码、人工数据：390px 与 1024px 的 `scrollWidth-clientWidth=0`；展开历史后也为 0。180×260px 短卡蒙版横向溢出 0，滚动后查看原文按钮可见。费用说明展开、查看原文解除蒙版均操作验证。
- 独立截图审阅后，将理由改为人话概括+分类分组，金额旁增加“非账户余额”；复审无阻塞或主要问题。截图数据是模拟值，不是实际模型结果。
- 实际 Jev 尝试 **1 次人工食谱文本**，客户端约 325ms 返回 network error，没有模型结果或 token 用量。累计正确记录 `calls=1, pricedCalls=0`，本次实际费用未知，未自动重试。只检查了密钥是否能构成合法请求头，未输出密钥；另一个不带鉴权的模型列表诊断请求返回 403，无法据此确认首次失败根因。尚未验证新格式的真实成功回答与服务端用量回传。

## 使用与复测

重新构建后在扩展管理页重新加载，再刷新小红书首页，避免旧页面协议不匹配。保持 OCR 健康再开始。
检查历史是否有正文及来源、实际 Jev state 的三个字段和六题输出。联网成功后观察美元累计；此前那一次人工测试的未知用量仍保留，不能补造为零费用。

离线 UI 复现：运行 `node scripts/preview-body-ui.mjs`，用 Chrome 打开生成的 `.tmp/body-ui.html`。数据均为模拟，不产生模型请求。

未覆盖：长时间滚动、不同账号/站点构建版本、两位开发者独立实测、中文误过滤率标定、真实账户账单核对。内部页面适配失效会降级，不承诺永久兼容。
