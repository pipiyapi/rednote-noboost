# 技术验证结论

**状态：假设 A 已完成；假设 B 与 C 的真实环境验证待继续。**

页面结构结论来自 2026-09-22 登录状态下的真实小红书网页版 `/explore`，使用
浏览器检查页面 DOM、内嵌初始状态，并在滚动前后比较卡片节点与笔记 ID。

## 假设 A：首页卡片能提供哪些判定材料

| 问题 | 结论 | 证据 |
| --- | --- | --- |
| 卡片的选择器是什么（用什么稳定属性定位） | 已确认 | 列表为 `#exploreFeeds`，卡片为 `section.note-item[data-note-id]`，标题为 `a.title`。 |
| 笔记 ID 从哪取、形态与长度 | 已确认 | 卡片 `data-note-id` 为 24 位十六进制；链接 `/explore/{id}` 可作降级来源。 |
| 首页数据里**有没有**正文（`desc`） | 没有 | 当前 DOM 只有卡片标题、作者、互动与封面；`__INITIAL_STATE__` 的 `noteCard` 也不含正文。唯一 `desc` 属于用户资料，不是笔记。 |
| 页面数据是否在页面世界（需 MAIN world 才能读） | 已确认但 V1 不需读取 | `__INITIAL_STATE__` 位于页面内嵌脚本，但其中没有正文；首个闭环无需跨世界通道。 |
| 滚动后 DOM 节点是否被回收复用 | 会复用 | 滚动前后均约 30 个卡片节点，但 `data-index` 与 `data-note-id` 已更新到后续批次。 |
| 首页 URL 形态：`/` 与 `/explore`，详情页是否为 `/explore/{id}` | 已确认核心路径 | 本次实测首页为 `/explore`；卡片链接为 `/explore/{24位id}`。 |

**影响**：首个闭环以标题为输入，OCR 保持为第二阶段备选；观察器监听新增节点和
`data-note-id` 变化，不能只用元素身份去重。正文获取需另行研究详情数据请求。
